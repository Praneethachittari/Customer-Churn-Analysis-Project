# Customer-Churn-Analysis-Project

This project focuses on analyzing customer churn in the telecommunications industry using Power BI and the Telco Customer Churn dataset. It explores customer demographics, contract types, tenure, internet services, payment methods, and additional services to understand churn patterns and potential revenue impact.

The dashboard uses Power Query for data cleaning and transformation, DAX for calculations and KPIs, and interactive visualizations to present meaningful business insights and recommendations that can support customer retention strategies.

**Tools Used:** Power BI, Power Query, DAX, Data Modeling, and Data Visualization.
